## Known issues / непроверенное

- Принятие/отклонение заявки и удаление дружбы проверены DB-тестами, но не в браузере получателя. Воспроизведение M4A отдельно не проверено; WAV проверен агентом, MP3 и фото в диалоге подтверждены пользователем. Для нового alias нужен доступный адрес и соответствующие Auth redirects.
- Прямой доступ третьего вошедшего пользователя к private attachments в реальном Storage отдельно не проверен; открытие чужого диалога отклонено по проверке пользователя. Файл незавершённого сообщения или загрузки аудио с неизвестным результатом может остаться в private Storage.

- Скорость на других устройствах, при холодном старте и под нагрузкой отдельно не измерялась.
- Выбранное фото незавершённого поста может остаться в Storage при закрытии страницы.
